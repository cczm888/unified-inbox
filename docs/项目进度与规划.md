### 2.2 已实现功能

**接入层**
- 飞书长连接事件订阅（`lark.ws.Client`，无需公网回调）
- 飞书 OpenAPI 历史回填（`POST /inbox/backfill`，实测一次拉回 19 条）
- 邮箱 IMAP 轮询收信 + SMTP 发信（含附件 MIME、HTML 转文本）
- Telegram 长轮询（`getUpdates`）+ 发送
- 钉钉 Stream 模式 + sessionWebhook 出站（未发布）
- **运行时接入平台**：网页填凭证即时生效，不用改 `.env`、不用重启
- 凭证 Fernet 加密存库（AES-128-CBC + HMAC-SHA256）

**处理层**
- 统一消息模型 `UnifiedMessage`（四平台字段集合完全一致，有测试守护）
- 状态机 `received → claimed → replied → closed`（可手改，气泡标签直接下拉）
- 优先级 `urgent / normal / low`（可手改，标签可点 × 清除）
- 未读/已读（`read_at` 与处理状态解耦）
- 待办：创建 / 改状态 / 回流原平台
- 批量操作：已读 / 改状态 / 改优先级（出站消息自动排除）

**出口层**
- Outbox 可靠投递：数据库队列 + `FOR UPDATE SKIP LOCKED` + 指数退避重试 + 死信
- Redis 令牌桶限流（飞书 900/min，钉钉 20/min）
- 发送文本、发送文件（20MB 上限，文件名清洗）、跨平台转发
- 引用历史消息回复（跨平台统一为"引用块 + 正文"）
- 状态回流默认关闭（可选勾选，避免刷屏）

**界面层**
- 三栏布局（会话列表 / 消息流 / 处理面板），SSE 实时推送
- 消息气泡带头像、日期分组、状态 pill、紧急标记
- 附件：图片缩略图预览、文件卡片下载
- 全局搜索（会话名 / 会话 ID / 消息正文，命中标黄）
- 桌面通知（仅后台标签页触发）
- 移动端单栏自适应（<900px 收起列表，带返回）
- 待办 tab、看板 tab（平均处理时长、各平台收发统计）

**运维层**
- 访问口令（Cookie + HMAC 签名，30 天免登录）
- 多实例隔离（`new-instance.ps1` 生成独立端口、独立库、独立口令）
- 桌面快捷方式一键启动（实测冷启动 19.3 秒）
- 局域网访问 + cloudflared 公网隧道
- Docker Compose 零依赖启动

**关键设计决策**

| 决策 | 理由 |
|---|---|
| 用长连接而非 Webhook | 免公网域名、免 HTTPS 证书、本地就能跑 |
| Outbox 而非直接调用 | 平台限流/宕机时不丢消息，可重试、可观测 |
| 引用用文本块而非平台原生引用 | 各平台原生引用 API 差异大，文本块保证跨平台一致 |
| 状态回流默认关闭 | 系统回执会把用户真实发言顶出视野，属于负优化 |
| 统一用 `platform_msg_id` 去重 | 实时事件与历史回填可能拿到同一条消息 |
| SQLite / PostgreSQL 双支持 | 本机无 Docker 也能开发，生产用 PG |
