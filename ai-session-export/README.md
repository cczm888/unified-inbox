## 关于"AI 生成"的说明

这套代码的每一行都是 AI 敲的，这一点不掩饰。但过程不是"给一句话，拿一个成品"：

- 赛题被读错四次（全量抓取、用户身份、RPA、边界条件），每次都是人指出来的；
- 部署安全、入站可靠性那批 P0 问题，是第三方审查发现的，AI 自己没检出来；
- 服务掉线五次、GitHub 推送断了十几次，都是现场排查出来的，不是预先设计好的。

文档里记录了这些失败。我们判断：**一份能自己推翻自己的记录，比一份通篇正确的总结更可信。**
